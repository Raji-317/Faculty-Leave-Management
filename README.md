Faculty Management and Class Adjustment
Website

This is a simple and user-friendly web application designed to help faculty members and
administrators manage class adjustments and leave requests efficiently. The website provides
an easy interface for applying, approving, and tracking class adjustments without the need for
paper forms or backend systems.

Features
Faculty Leave Application: Teachers can fill out and submit leave requests.
Class Adjustment Management: Faculty can plan and adjust their classes when on leave.
Admin View: HODs and Principals can view submitted forms and take action manually.
Clean User Interface: Built using pure HTML and CSS for simplicity and easy navigation.

🧩 Tech Stack
HTML5 – For structuring the website
CSS3 – For styling and layout design
JavaScript (optional) – For interactive functionality (if used)
